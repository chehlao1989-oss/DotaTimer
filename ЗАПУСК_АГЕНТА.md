# Как запустить агента (Claude Code) для проекта «Dota таймер»

## 0. Что нужно
- **Подписка Claude Pro или Max.** На бесплатном плане Claude Code не работает.
- Windows 10 (версия 1809 или новее) или Windows 11.
- PyCharm (уже есть).

## 1. Один раз: установить программы

**Python 3.12**
1. Скачать с https://www.python.org/downloads/ (версию 3.12.x).
2. В установщике **обязательно поставить галочку «Add python.exe to PATH»**.
3. Проверка: открыть PowerShell, набрать `python --version`, должно появиться `Python 3.12.x`.

**Git for Windows** (рекомендуется: агент сохраняет с его помощью историю изменений и работает стабильнее)
1. Скачать с https://git-scm.com/downloads/win и установить, все настройки оставить по умолчанию.
2. Проверка: `git --version`.

**Claude Code**
1. Открыть **PowerShell** (Пуск → набрать «PowerShell»). Права администратора не нужны.
2. Вставить команду и нажать Enter:
   ```powershell
   irm https://claude.ai/install.ps1 | iex
   ```
3. **Закрыть PowerShell и открыть заново.**
4. Проверка: `claude --version` должен показать номер версии.
   Если пишет «claude не распознано», перезагрузи компьютер и попробуй снова.

## 2. Каждый раз: запуск в PyCharm

1. PyCharm → **File → Open** → выбрать папку `C:\Claude_agent\DotaTimer` → OK.
2. Открыть терминал внутри PyCharm: **Alt+F12** (или вкладка Terminal внизу).
3. Набрать `claude` и нажать Enter.
4. **Только в первый раз**: откроется браузер, нужно войти в аккаунт Claude. Потом вернуться в PyCharm.
5. Если спросит «Do you trust the files in this folder?», ответить **Yes**.

Агент сам прочитает `CLAUDE.md`: там ТЗ, правила и словарь доты.

Вместо терминала можно использовать приложение Claude для компьютера (вкладка Code, выбрать эту папку). Работает так же, просто это окно, а не консоль.

## 3. Первое сообщение агенту
Скопируй и отправь:
```
Привет. Прочитай CLAUDE.md и docs/TZ.md. Начинаем фазу 0: дай план, потом делай.
```

## 4. Как работать с агентом

**Разрешения.** Перед тем как создать файл или запустить команду, агент спрашивает разрешение:
- `Yes`: разрешить один раз;
- `Yes, and don't ask again…`: разрешить такое действие дальше без вопросов (удобно для `pytest`, `python`, `pip`);
- `No`: запретить, после этого напиши, что сделать иначе.

Читай, что он собирается сделать. Если команда удаляет что-то вне папки проекта, отвечай «No».

**Полезные клавиши и команды**
| Что | Как |
|---|---|
| Остановить агента посреди работы | **Esc** |
| Переключить режим (обычный → сам принимает правки → только план) | **Shift+Tab** |
| Начать новую тему с чистого листа | `/clear` |
| Продолжить прошлый разговор после закрытия | запустить `claude --continue` |
| Справка | `/help` |
| Выйти | `/exit` или Ctrl+C два раза |

**Советы**
- **Одна фаза или одна задача = один разговор.** Закончили задачу → `/clear` → новая. Так агент меньше путается.
- Для крупной задачи сначала попроси план: «Сначала только план, код не пиши». Режим «только план» включается через Shift+Tab.
- Если что-то не работает, скопируй агенту текст ошибки целиком и опиши, что делал.
- Для проверок в игре агент даст чек-лист. После игры напиши ему результат: что сработало, что нет, на какой минуте.
- Хочешь поменять требования? Скажи агенту: «Обнови ТЗ: …». ТЗ должно оставаться главным документом.
- Код запускает агент, но можно и самому: зелёная кнопка ▶ в PyCharm или `python -m app.main` в терминале. Как именно, агент подскажет после каждой задачи.
