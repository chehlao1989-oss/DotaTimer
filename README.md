# Dota таймер

Бесплатный помощник для Dota 2 под Windows.

- **Таймеры**: руны силы (с акцентом на первую активку на 6:00), баунти, водные руны, святилища мудрости, лотосы, терзатель, день и ночь, осадные крипы, тиры нейтралок. Голосом и короткой надписью поверх игры. Режимы «Обычный» и «Турбо».
- **Угрозы и контр-предметы** (в разработке): программа узнаёт героев по верхней панели, выбирает 1–2 главные угрозы и подсказывает контр-предметы по факту — когда вы сами кликаете по врагу и видите его инвентарь.

Интерфейс на русском.

## Безопасно ли это для аккаунта

Программа использует **только** то, что Valve разрешает и что вы и так видите:

- **Game State Integration (GSI)** — официальный механизм Valve, игра сама отправляет данные о **вашем** герое и игровом времени;
- **то, что видно на экране**: верхняя панель с портретами героев и инвентарь врага, по которому **вы сами** кликнули;
- открытую статистику уже сыгранных публичных матчей (Steam Web API, OpenDota) — она собирается не у вас на компьютере, а раз в сутки на GitHub и скачивается одним файлом.

Программа **не читает память игры**, не внедряется в процесс, не перехватывает сетевой трафик, **не нажимает клавиши и не кликает** в игре, не смотрит данные идущего матча и профили соперников.

## Установка (для разработки, пока нет готовой сборки)

Нужны Windows 10/11, Python 3.12 и Git.

```
git clone https://github.com/chehlao1989-oss/DotaTimer.git
cd DotaTimer
py -3.12 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m app.main
```

В Dota 2 поставьте режим экрана **«В окне без рамки»** (Настройки → Видео): поверх полноэкранного режима надписи не видны. Файл настроек GSI программа кладёт в папку игры сама. Если Дота была запущена, перезапустите её.

При первом запуске программа один раз генерирует голосовые фразы (нужен интернет). Любую фразу можно заменить своим файлом `%APPDATA%\DotaTimer\voice\<имя>.wav`.

Настройки, кеш и логи лежат в `%APPDATA%\DotaTimer\`.
