# Dota таймер

Бесплатный помощник для Dota 2 под Windows.

- **Таймеры**: руны силы (с акцентом на первую активку на 6:00), баунти, водные руны, святилища мудрости, лотосы, терзатель, день и ночь, осадные крипы, тиры нейтралок. Голосом и короткой надписью поверх игры. Режимы «Обычный» и «Турбо».
- **Угрозы и контр-предметы**: программа узнаёт героев по верхней панели, выбирает 1–2 главные угрозы и показывает справа полоску с контр-предметами для вашего героя. Когда вы сами кликаете по врагу и у него появляется заметный предмет — подсказка, чем ответить. Советуется только «настоящий контр-предмет»: тот, который против этого врага игроки на вашем герое берут заметно чаще (по ~1,7 млн сыгранных публичных матчей); если такого нет, программа молчит.

Интерфейс на русском.

## Безопасно ли это для аккаунта

Программа использует **только** то, что Valve разрешает и что вы и так видите:

- **Game State Integration (GSI)** — официальный механизм Valve, игра сама отправляет данные о **вашем** герое и игровом времени;
- **то, что видно на экране**: верхняя панель с портретами героев и инвентарь врага, по которому **вы сами** кликнули;
- открытую статистику уже сыгранных публичных матчей (Steam Web API, OpenDota) — она собирается не у вас на компьютере, а раз в сутки на GitHub и скачивается одним файлом.

Программа **не читает память игры**, не внедряется в процесс, не перехватывает сетевой трафик, **не нажимает клавиши и не кликает** в игре, не смотрит данные идущего матча и профили соперников.

## Установка

1. Скачайте `DotaTimer-<версия>.zip` из раздела [Releases](https://github.com/chehlao1989-oss/DotaTimer/releases) и распакуйте в любую папку (например, `C:\Games\DotaTimer`).
2. Запустите `DotaTimer.exe`. Python не нужен.
3. Если Windows покажет «Система Windows защитила ваш компьютер» — нажмите **«Подробнее» → «Выполнить в любом случае»**. Программа не подписана платным сертификатом, поэтому Windows её «не знает». Некоторые антивирусы так же ошибочно ругаются на программы, собранные PyInstaller; исходный код открыт в этом репозитории.
4. В Dota 2 поставьте режим экрана **«В окне без рамки»** (Настройки → Видео): поверх полноэкранного режима надписи не видны. Файл настроек GSI программа кладёт в папку игры сама; если Дота была запущена — перезапустите её.

При первом запуске программа один раз генерирует голосовые фразы и скачивает справочники и иконки (нужен интернет). Любую фразу можно заменить своим файлом `%APPDATA%\DotaTimer\voice\<имя>.wav`. Настройки, кеш и логи — в `%APPDATA%\DotaTimer\`.

Горячие клавиши (меняются в окне программы): `Ctrl+Alt+T` — терзатель убит, `Ctrl+Alt+M` — тишина, `Ctrl+Alt+H` — скрыть/показать полоску угроз, `Ctrl+Alt+P` — выбрать врагов вручную, `Ctrl+Alt+I` — «вижу у врага предмет».

Удаление: выключите автозапуск в окне программы (если включали), удалите папку программы и `%APPDATA%\DotaTimer`.

## Запуск из исходников (для разработки)

Нужны Windows 10/11, Python 3.12 и Git.

```
git clone https://github.com/chehlao1989-oss/DotaTimer.git
cd DotaTimer
py -3.12 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m app.main
```

## Для разработчиков

- Тесты: `pytest`
- Сборка exe: `pip install -r requirements-build.txt`, `python tools/make_icon.py packaging/dotatimer.ico`, `pyinstaller packaging/DotaTimer.spec` → `dist/DotaTimer/`; на GitHub — запуск «Сборка программы» (Actions)
- Запись матча для тестов: `python tools/gsi_recorder.py`
- Техническое задание: [docs/TZ.md](docs/TZ.md)
