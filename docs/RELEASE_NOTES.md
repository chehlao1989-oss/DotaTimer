«Dota таймер» 0.2.4 — защита от падений.

**Что нового**
- Если программа вдруг закроется посреди катки, она сама перезапустится в трей через несколько секунд — таймеры и подсказки продолжат работать.
- Причина такого падения записывается в файл `%APPDATA%\DotaTimer\logs\crash.log` — если это случилось, пришлите его вместе с `dotatimer.log`.
- Из 0.2.3: подсказки по предметам врага по их свойствам (с проверкой по Dota 2 Wiki), правило «замедление», чтение золотых имён, подсказка про оверлей FPS.

**Установка**: скачайте zip ниже, распакуйте, запустите `DotaTimer.exe` (Python не нужен). Если стояла прошлая версия — закройте её (трей → «Выход») и распакуйте новую папку вместо старой; настройки сохранятся.

**Безопасность**: только Game State Integration (официальный механизм Valve) и то, что видно на экране. Программа не читает память игры, не нажимает клавиши за вас, не смотрит данные идущего матча.
