«Dota таймер» 0.2.5 — подсказки понятнее, зрение точнее.

**Что нового**
- **F11** — показать ещё раз последние подсказки по предметам врага (до 3, без голоса): если в драке не успели прочитать, нажмите, пока ждёте возрождения. Клавишу можно сменить на вкладке горячих клавиш.
- Совет против героя теперь с причиной: например, «Lotus Orb (отражает Stifling Dagger)».
- Программа читает имя и предметы героя, у которого широкая нижняя панель (Rubick, Invoker).
- Точнее узнаются имена врагов и меньше путаницы после смены катки.
- Убрано напоминание об осадных крипах.
- Из 0.2.4: если программа закроется посреди катки, она сама перезапустится в трей.

**Установка**: скачайте zip ниже, распакуйте, запустите `DotaTimer.exe` (Python не нужен). Если стояла прошлая версия — закройте её (трей → «Выход») и распакуйте новую папку вместо старой; настройки сохранятся.

**Безопасность**: только Game State Integration (официальный механизм Valve) и то, что видно на экране. Программа не читает память игры, не нажимает клавиши за вас, не смотрит данные идущего матча.
