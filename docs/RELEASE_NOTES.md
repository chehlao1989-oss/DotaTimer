«Dota таймер» 0.2.3 — подсказки по предметам заново.

**Что нового**
- Подсказки по предметам врага переделаны: ответ подбирается по свойству предмета (уклонение, лечение, невидимость, замедление…), каждая связка проверена по Dota 2 Wiki. Из подходящих ответов показываются 1–2, которые реально собирают на вашем герое; если таких нет — самый универсальный с пометкой «редко на твоём герое».
- На дешёвые и стартовые предметы (Magic Wand, Quelling Blade, Helm of Iron Will) подсказок больше нет.
- Против главных угроз — предметы со страниц Counters Dota 2 Wiki; строк «явного ответа нет» в карточке больше нет. Под иконками на полоске — ничего, название предмета — 5 секунд при смене совета.
- Предметы врага читаются, даже когда его имя в нижней панели золотое (раньше в таких катках программа не видела ни одного предмета).
- Если портреты слева вверху закрывает оверлей FPS (MSI Afterburner / RTSS), программа скажет об этом и предложит выбрать врагов вручную (Ctrl+Alt+P).

**Установка**: скачайте zip ниже, распакуйте, запустите `DotaTimer.exe` (Python не нужен). Если стояла прошлая версия — закройте её (трей → «Выход») и распакуйте новую папку вместо старой; настройки сохранятся.

**Безопасность**: только Game State Integration (официальный механизм Valve) и то, что видно на экране. Программа не читает память игры, не нажимает клавиши за вас, не смотрит данные идущего матча.
