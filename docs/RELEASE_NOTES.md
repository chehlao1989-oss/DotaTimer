«Dota таймер» 0.2.7 — примерное время покупки контр-предметов.

**Что нового**
- Рядом с советом и под иконкой предмета показывается примерная минута покупки: «≈25 мин» / «≈25м».
- Время считается по первым покупкам готового предмета в разобранных завершённых матчах OpenDota: отдельно для твоего героя, Normal/Turbo и роли. Это статистический ориентир, а не обязательная очередь закупа.
- Когда наблюдений мало или данные устарели, совет остаётся без минуты. Без интернета используется сохранённая статистика.
- Исправлено серверное хранение матчей: новые уникальные матчи заменяют ровно столько же старых; пересчёт снова работает.

**Установка**: распаковать архив и запустить `DotaTimer.exe`. Перед заменой прежней версии закрыть её через трей → «Выход». Настройки сохранятся.

**Проверка в игре**: минуты покупки ещё ожидают подтверждения автора; список — `docs/test_plan.md`.

«Dota таймер» 0.2.6 — повтор подсказок про героев и зрение точнее.

**Что нового**
- **F11** — сначала ещё раз показывает карточку про опасных героев врага с советами против них; нажмите F11 ещё раз (в течение 20 с) — последние подсказки по предметам врага. Без голоса, удобно, пока ждёте возрождения.
- Против героев больше не советуются Magic Stick, Magic Wand, Tango и подобное — только предметы с понятной причиной.
- Программа узнаёт ярко-золотые имена героев (например, выделенный враг Invoker) и длинные имена (Phantom Assassin) — подсказки по предметам врагов приходят чаще.
- Из 0.2.5: причины в советах («Lotus Orb (отражает Stifling Dagger)»), Rubick и Invoker с широкой панелью.

**Установка**: скачайте zip ниже, распакуйте, запустите `DotaTimer.exe` (Python не нужен). Если стояла прошлая версия — закройте её (трей → «Выход») и распакуйте новую папку вместо старой; настройки сохранятся.

**Безопасность**: только Game State Integration (официальный механизм Valve) и то, что видно на экране. Программа не читает память игры, не нажимает клавиши за вас, не смотрит данные идущего матча.
