Первый выпуск «Dota таймер».

**Что умеет**
- Таймеры: руны силы (акцент на первую активку на 6:00), баунти, водные руны, святилища мудрости, лотосы, терзатель, день и ночь, осадные крипы, тиры нейтралок — голосом и надписью поверх игры. Режимы «Обычный» и «Турбо».
- Угрозы и контр-предметы: герои по верхней панели, 1–2 главные угрозы, полоска справа с «настоящими контр-предметами» для вашего героя (по сыгранным публичным матчам), подсказка по клику на врага с новым предметом.

**Установка**: скачайте zip ниже, распакуйте, запустите `DotaTimer.exe` (Python не нужен). Подробно — в README.

**Безопасность**: только Game State Integration (официальный механизм Valve) и то, что видно на экране. Программа не читает память игры, не нажимает клавиши за вас, не смотрит данные идущего матча.
