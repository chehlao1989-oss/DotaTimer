«Dota таймер» 0.2.0 — новое оформление.

**Что нового**
- Окно программы: новый значок (секундомер), полупрозрачные панели поверх фона. В катке на фоне — ваш герой, вне катки — карта или своя картинка («Выбрать фон…»). Картинки фона программа берёт с сервера Valve при первом запуске.
- Шрифты как в Доте (Radiance и Reaver из папки игры; если Доты нет — похожие свободные шрифты).
- Надписи поверх игры — шрифтом Доты, ярче: прозрачность из настроек меняет только подложку, текст всегда виден.
- Полоска угроз крупнее, под иконками — названия предметов. Угроза без явного контр-предмета остаётся на полоске с подписью «нет явного ответа».
- Советы считаются по свежим публичным матчам дважды в сутки (сейчас — больше 4 млн матчей).

**Установка**: скачайте zip ниже, распакуйте, запустите `DotaTimer.exe` (Python не нужен). Подробно — в README. Если стояла 0.1.0 — закройте её (трей → «Выход») и распакуйте новую папку вместо старой; настройки сохранятся.

**Безопасность**: только Game State Integration (официальный механизм Valve) и то, что видно на экране. Программа не читает память игры, не нажимает клавиши за вас, не смотрит данные идущего матча.
