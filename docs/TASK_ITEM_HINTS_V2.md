## Причина (не симптом)
Метрика A (насколько чаще берут X, когда у врага есть Y) считается по ФИНАЛЬНЫМ инвентарям, без времени покупки. «У врага есть дорогой предмет» ≈ «игра длинная и богатая» → в такой игре ты тоже собрал больше своих обычных предметов. Страты по длительности это не убирают. Дешёвые предметы (Wand, Stick, Quelling) в финальном инвентаре — признак короткой/бедной игры, отсюда мусорные связи.
Это ошибка дизайна (RECOMMENDER_SPEC, Claude), а не порога. Подкручивание порогов, λ, сглаживания не поможет — не тратить на это время.

## Новый дизайн (обратимый: сырые матчи и старый расчёт не удалять)
1. **Слой «механика» — основной.** Предмет врага → свойства (флаги уже есть в meta: evasion, invisibility, heal, passives, illusions, saves, magic_immunity, mobility, spell_block, magic_damage, physical_damage, disables, armor). Свойство → список контр-предметов.
   - Таблица `data/item_counters.json`: для каждого флага — контр-предметы и короткая причина словами («пробивает уклонение»). У каждой строки `source` (страница Dota 2 Wiki: Counters/описание предмета, или описание Valve) и `checked_patch`. Нет источника → `verified: false`, не показывать.
   - Подсказка срабатывает ТОЛЬКО на предметы, у которых есть флаг. Дешёвые/стартовые предметы без флага не вызывают подсказку никогда.
   - Сборка по частям (Perseverance → Khanda, Reaver → Overwhelming Blink) остаётся, флаги берутся у итогового предмета.
2. **Слой «твой герой» — только выбор из списка механики.** Из списка контр-предметов показать 1–2, которые реально собирают на ТВОЁМ герое и роли: доля матчей, где этот предмет куплен на твоём герое (обычная частота покупки, не lift). Если ни один из списка на твоём герое не берут чаще ~2% — показать самый универсальный с пометкой «редко на твоём герое».
3. **Статистика A/B** остаётся как проверка и отчёт, но не решает, что показывать.
4. Карточка «Главные угрозы»: строки «→ явного ответа нет» не показывать вообще. Для угроз-героев — тот же подход: свойства героя (флаги) → контр-предметы из таблицы → выбор под твоего героя.
