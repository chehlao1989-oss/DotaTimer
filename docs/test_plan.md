# Что проверить в игре (общий список)

Сюда копится всё, что нельзя проверить без настоящей катки. Проверяем одним заходом, когда соберётся крупный кусок.

## Фаза 1: таймеры (обычный режим)
- [ ] В окне «Ожидание игры…» → «Dota 2 подключена ✓» после входа в катку
- [ ] «Настроить расположение надписей»: перетащить, правый клик — готово, после перезапуска место сохранилось
- [ ] 1:50 вода, 3:50 баунти + вода одной плашкой, 4:45 ночь, 5:30 и 5:50 активка
- [ ] Клики проходят сквозь надписи, надписи не прячутся за Дотой
- [ ] В паузе ничего не звучит
- [ ] Ctrl+Alt+T после убийства терзателя → «Таймер терзателя запущен», через 10 мин «Терзатель появился»
- [ ] Ctrl+Alt+M → тишина на минуту
- [ ] Крестик прячет окно в трей, «Выход» в трее закрывает программу

## Фаза 2: угрозы и зрение (олпик, живая катка)
- [ ] В начале катки (после горна) карточка «Главные угрозы» появилась сама, враги узнаны правильно
- [ ] Если враг не узнан — Ctrl+Alt+P, выбрать вручную, карточка обновилась
- [ ] Клик по портрету врага вверху, у которого есть заметный предмет (Heart, BKB, Butterfly…) → подсказка «У X появился Y → …»
- [ ] Клик по врагу, у которого есть компонент (например, Ogre Axe) → «X собирает BKB (есть Ogre Axe)»
- [ ] Смерть → один раз «Кликни по врагам вверху»
- [ ] Ctrl+Alt+I → окно «Вижу у врага предмет» работает
- [ ] Ctrl+Alt+H → карточка угроз ещё раз
- [ ] Игра не подтормаживает (FPS как обычно)

## (выполнено) Разведка для фазы 2: инвентарь врага
Скриншоты делать клавишей **F12** (скриншот Steam, в полном разрешении). Агент сам заберёт их из папки Steam.
- [ ] Скрин 1: выделен свой герой (нижняя панель в обычном виде)
- [ ] Скрин 2: клик по портрету врага в верхней панели, враг **виден** на карте
- [ ] Скрин 3: клик по портрету врага, который **в тумане** (не виден): показывается ли инвентарь?
- [ ] Скрин 4: клик по портрету **мёртвого** врага
- [ ] Скрин 5: враг с 4+ предметами (ближе к 10–15 мин, боты успевают закупиться)
- [ ] Заметка: двигается ли камера при одиночном клике по портрету; F1 возвращает выделение на своего героя

## Турбо (режим «Турбо» в окне программы)
- [ ] 10:00 — появился ли терзатель (таймер у миникарты)
- [ ] После убийства терзателя сразу Ctrl+Alt+T и запомнить минуту: через сколько появился снова (программа ждёт 5 мин)
- [ ] 7:30, 12:30, 17:30, 30:00 — открывается ли новый тир нейтралок
