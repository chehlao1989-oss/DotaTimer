# Словарь: как мы говорим о Доте

Этот словарь нужен, чтобы агент и автор говорили на одном языке. Правила:
- **В общении с автором** можно и нужно использовать этот сленг — **кроме предметов**: предметы всегда полным английским названием, как в магазине игры (`Daedalus`, `Scythe of Vyse`, `Eul's Scepter of Divinity`), в игре они на английском даже в русской версии, так их проще искать (решение автора 30.09). В отчётах с советами рядом с названием — иконка предмета.
- **В интерфейсе программы** названия героев и предметов на английском, как в игре (`Black King Bar`, `Heart of Tarrasque`). Сленг допустим только в коротких голосовых фразах и подсказках, если он общепринятый («активка», «БКБ»).
- **В коде** только официальные английские названия и внутренние id (`black_king_bar`, `heart`).
- Если автор использует слово, которого здесь нет, и значение неочевидно, уточни и добавь его сюда.

## Роли и позиции
| Сленг | Значение |
|---|---|
| **pos 1 / единичка / керри** | Главный фармящий герой, раскрывается к поздней игре, «тащит» |
| **pos 2 / мидер / мид** | Герой центральной линии |
| **pos 3 / тройка / оффлейнер / хардлейнер** | Герой сложной линии (оффлейн) |
| **pos 4 / четвёрка / роумер** | Активный саппорт, ходит по карте, помогает на линиях |
| **pos 5 / пятёрка / фулл саппорт** | Саппорт, который стоит с керри, ставит варды, покупает расходники |
| **коры** | Позиции 1–3, те, кому нужен фарм |
| **сапорты / сапы** | Позиции 4–5 |
| **затащить / тащер** | Выиграть игру за счёт одного сильного героя, обычно керри в лейте |

## Режимы и ранги
| В игре | Как говорят |
|---|---|
| Ranked | рейтинг, ранкед |
| Unranked / обычная | обычка, анранкед |
| Turbo | турбо |
| All Pick / Captains Mode / Single Draft | олпик / СМ, капитанский / сингл драфт |
| MMR | ммр, птс, рейтинг |
| Ранги (по возрастанию) | Рекрут (Herald), Страж (Guardian), Рыцарь (Crusader), Герой (Archon), Легенда (Legend), Властелин (Ancient), Божество (Divine), Титан (Immortal) |

В OpenDota ранг приходит числом `rank_tier` (например, 54 = Легенда 4): первая цифра обозначает ранг (1 = Рекрут … 8 = Титан), вторая цифра — звезду.
